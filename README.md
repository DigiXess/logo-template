> 

## How to setup new repository?

  After creating a new repository,
-  Change [config/env.sh](config/env.sh) file to set the website name, URL, admin email, username, and password.
-  run the following command to update the repository files:
  ```bash
  source ./config/env.sh # Once on every terminal session
  update-repo
  ```
- follow the guidelines in the [First Time Configuration](/docs/first-time-config.md "First Time Configuration") document.
