# First Time Repository Configuration

This document outlines the steps to configure the <<brand-name>> logo repository for the first time. It includes essential configurations,  repo setup, and initial asset organization.

## Do the following Configurations

1. Make sure the following files are changed
    - [README](/README.md)
    - [LICENSE](/LICENSE.md)
    - [CONTRIBUTING](/CONTRIBUTING.md)
    - [CHANGELOG](/CHANGELOG.md)
1.  Make sure the following files and folders are deleted
    - [docs/repo](/docs/repo)
    - remove [docs/first-time-config](/docs/first-time-config.md) file after completing the configurations.
    - All files in the [`logs/`](/logs/) folder.
    - update-repo file in the [`scripts/update-repo`](/scripts/update-repo ) file.
    - Remove all other files not needed.
